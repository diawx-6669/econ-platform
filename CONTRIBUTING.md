# Как вносить изменения

1. Создайте ветку от `main`: `git checkout -b feature/название`.
2. Для backend — `cd backend && npm install`, для запуска в dev-режиме —
   `npm run dev`.
3. Frontend не требует сборки — просто открывайте `frontend/public/index.html`.
4. Придерживайтесь структуры: новая функциональность backend оформляется как
   отдельные `controller` + `route` + (при необходимости) `model`, а не
   добавляется в существующие файлы вперемешку.
5. Перед PR убедитесь, что `npm test` в `backend/` проходит (CI это тоже
   проверит автоматически).
6. Коммиты — в повелительном наклонении, по-русски или по-английски, но
   последовательно в рамках одного PR: `Добавить восстановление пароля`.

## Стиль кода

- Backend: обычный CommonJS, `async/await`, без лишних абстракций на старте.
- Frontend: vanilla JS без сборки — если требуется фреймворк, обсудите это в
  issue перед тем, как переписывать.
- Все текстовые сообщения пользователю — на русском, в дружелюбном и коротком
  тоне (см. `docs/DESIGN.md`).

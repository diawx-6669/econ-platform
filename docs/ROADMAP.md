# Roadmap

Текущий этап закрывает только вход/регистрацию. Дальше — по мере роста
платформы, разделами (модулями), а не одним большим куском:

## Ближайшее

- [ ] Подтверждение email после регистрации
- [ ] Восстановление пароля («Забыли пароль?» уже есть в UI, логики пока нет)
- [ ] Личный кабинет (`dashboard.html` — сейчас заглушка)

## Обучающий контент

- [ ] Модуль курсов: `backend/src/{models,controllers,routes}/course.js`
- [ ] Модуль уроков с интерактивными заданиями (квизы, симуляции рынка,
      калькуляторы — «чуть-чуть интерактива», как и задумано)
- [ ] Прогресс ученика по курсам

## Инфраструктура

- [ ] Переезд с `lowdb` на PostgreSQL/MongoDB при росте нагрузки
- [ ] Переезд frontend на React/Next.js, если понадобится более сложная
      логика состояния (сейчас vanilla JS осознанно, чтобы не тащить лишнее)
- [ ] Docker-compose для локальной разработки
- [ ] Полноценные тесты (Jest/Supertest для backend)

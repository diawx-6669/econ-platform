# Дизайн-система: экран входа

## Идея

Тёмный «космический» фон с плавно движущимися размытыми пятнами света
(аврора/mesh-градиент) — создаёт ощущение технологичности и глубины, не
отвлекая от формы. Слева — брендовая панель с анимированным графиком роста
(отсылка к теме экономики), справа — стеклянная карточка входа/регистрации.

## Цвета

| Токен       | Hex       | Назначение                          |
|-------------|-----------|--------------------------------------|
| `--bg`      | `#080b16` | Базовый фон                          |
| `--violet`  | `#7c5cff` | Аврора-пятно, акценты                 |
| `--teal`    | `#2dd4da` | Аврора-пятно, основной акцент, ссылки |
| `--pink`    | `#e94f9e` | Аврора-пятно, ошибки/предупреждения   |
| `--gold`    | `#f2b84b` | Акцент кнопки (тема денег/роста)      |
| `--ink-0/1/2` | `#f5f6fb / #b9bfd4 / #7c839c` | Текст: основной / вторичный / приглушённый |

## Типографика

- **Display** — `Space Grotesk` (заголовки, wordmark, логотип) — геометричный,
  современный, не банковский и не "учебниковый".
- **Body** — `Inter` (основной текст, поля форм).
- **Mono** — `JetBrains Mono` (бегущая строка с экономическими показателями —
  отсылка к биржевому тикеру).

## Сигнатурный элемент

Анимированный SVG-график роста в левой панели: линия «прорисовывается» при
загрузке страницы (`stroke-dashoffset`), заливка под ней проявляется следом, а
точка на конце пульсирует. Это единственный смысловой акцент, привязанный к
теме экономики — весь остальной интерфейс сдержан.

## Взаимодействие

- Переключение «Вход / Регистрация» — табы с плавающим индикатором
  (`transform: translateX`), без перезагрузки и без резких скачков layout.
- Поля — плавающие подписи (`label` поднимается при фокусе/заполнении).
- Пароль — переключатель видимости, индикатор надёжности пароля для
  регистрации.
- Кнопка отправки — состояние загрузки (спиннер) на время запроса к API.
- `prefers-reduced-motion` уважается: анимации пятен и графика отключаются.

## Как переиспользовать

Все токены объявлены как CSS-переменные в `main.css` (`:root`). Чтобы
адаптировать дизайн под новую страницу (например, будущий каталог курсов),
подключите `main.css` и используйте те же переменные — фон и типографика
останутся едиными по всему сайту.
